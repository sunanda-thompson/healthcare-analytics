## 📁 Projects

### [Medicare Provider Utilization & Payment Analysis, CY2024](Medicare-Provider-Service-2024/)
Analysis of 352,948 Medicare fee-for-service records across Internal Medicine, Family Practice, Cardiology, and Psychiatry providers in Texas, Florida, and Georgia. Built in Excel (cleaning, pivot tables) and Power BI (5-page interactive dashboard) to answer utilization, cost/payment gap, geographic comparison, and provider performance questions aligned to payer reporting workflows.
**[View README and full findings](Medicare-Provider-Service-2024/README.md)**

### [Medicare Part D Prescriber Spend Analysis, Texas 2022](Medicare-PartD-2022/)
Analysis of 908,137 Medicare Part D prescriber-drug records across the same four specialties, using PostgreSQL for the full data workflow (extract, wrangle, analyze), with results delivered through an Excel workbook and slide presentation. Identifies a 10.6x cost-per-patient gap between brand-name and generic-focused prescribers, among other cost-driver findings.
**[View README and full findings](Medicare-PartD-2022/README.md)**
